The repository composes four sibling modules around a single contract: the FastAPI backend exposes `/diagnose` (multipart image upload) and `/ask-followup` (JSON Q&A) endpoints that the React frontend calls via `VITE_API_BASE_URL`. Backend configuration is centralized in `.env.example`, which declares both server settings (`BACKEND_PORT`, `CORS_ALLOW_ORIGINS`) and the pluggable AI provider keys (`DASHSCOPE_API_KEY`, `DASHSCOPE_BASE_URL`, `DASHSCOPE_MODEL`) consumed by the backend's `DiagnosisProvider` protocol; when no key is set the backend falls back to deterministic mock responses so the frontend can run fully offline. The `data/` module supplies the bilingual knowledge base and curated images that underpin both diagnosis and follow-up answers, while `documentation/` holds static artifacts such as the Render config for the backend demo. A shared top-level `requirements.txt` pins the Python runtime dependencies used by the backend and its pytest suite, and the root `README.md` documents the end-to-end startup sequence (backend first on port 8000, then frontend on 5173).
