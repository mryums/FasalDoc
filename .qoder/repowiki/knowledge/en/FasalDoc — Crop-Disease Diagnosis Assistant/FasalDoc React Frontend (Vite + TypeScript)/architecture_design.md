Single-page app rooted at `src/main.tsx` which renders `<App>` inside a `LanguageProvider` (i18n context) and global CSS tokens. `App.tsx` owns the entire application state via a single `useReducer` over a `FlowState` discriminated-union `Action` type, driving a screen-based router (`login | signup | dashboard | home | upload | analyzing | result | followup`) rendered as conditional JSX — no client-side routing library is used. The app is split into three layers: (1) `pages/` for full-screen screens, (2) `components/` for reusable UI pieces (Button, CameraCapture, VoiceInput, ImageUploader, ChatMessage, etc.), and (3) `services/` for all side effects — `api.ts` centralizes fetch calls to the FastAPI backend (`/diagnose`, `/ask-followup`) and normalizes errors into an `ApiError` with `kind: 'validation' | 'network' | 'server'`, while `auth.ts` provides a localStorage-backed mock auth layer (session + accounts) ready to be swapped for real endpoints. Shared contracts live in `types/api.ts`, mirroring the backend Pydantic models so components stay type-safe against the API. Internationalization is provided by `i18n/LanguageContext.tsx` plus `translations.ts`, persisting the chosen language and setting `dir='rtl'` for Urdu.
