The module is organized in a thin-layer FastAPI application: `main.py` creates the `FastAPI` app, configures CORS via `CORS_ALLOW_ORIGINS`, and mounts two routers. `routes/diagnose.py` and `routes/followup.py` define the `/diagnose` (image upload) and `/ask-followup` endpoints; they perform input validation through `utils/validators.py` (`validate_image_type`, `validate_image_size`, `validate_question`) and delegate business logic to `services/diagnosis_service.py`. The service layer defines a `DiagnosisProvider` Protocol and a `MockDiagnosisProvider` implementation, with a lazy `_build_provider()` factory that checks for `DASHSCOPE_API_KEY` and dynamically imports a real `backend.services.qwen_provider.create_provider()` when present, otherwise falling back to the offline mock — so routes never hardcode AI calls. Shared request/response contracts live in `models.py` as Pydantic v2 models with JSON schema examples mirrored by the frontend. Dependency direction is strictly routes → services → providers, with validators and models as leaf utilities.
